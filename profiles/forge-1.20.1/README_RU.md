# Forge 1.20.1 · Port Lab

Это отдельный профиль лаунчера для портирования модов на Minecraft 1.20.1.

- Файлы профиля кладутся в `client/` по той же структуре, что и в основной сборке: `mods/`, `config/` и так далее.
- Основная сборка 1.12.2 и этот профиль никогда не используют одну папку игры.
- Java 17 и Forge 47.4.10 лаунчер устанавливает автоматически.
- Обычная кнопка `1 - ОБНОВИТЬ МАНИФЕСТ.cmd` обновляет оба профиля.
