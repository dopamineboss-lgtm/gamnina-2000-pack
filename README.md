# Gamnina 2000 — клиентская сборка и автообновления

Это публичный файловый репозиторий лаунчера Gamnina 2000 для лицензионного Minecraft. Основной профиль — сборка Forge 1.12.2; отдельный Forge 1.20.1 Port Lab предназначен для разработки и портирования модов.

Игроку нужен только крошечный файл [`launcher/Gamnina2000Launcher.exe`](launcher/Gamnina2000Launcher.exe). При первом запуске он устанавливает свою рабочую копию в `%LOCALAPPDATA%\Gamnina2000\launcher`, создаёт на рабочем столе ярлык **Gamnina 2000**, проверяет `launcher/channel.txt`, безопасно обновляет основное ядро лаунчера и запускает его. Ядро сверяет файлы выбранного профиля по размеру и SHA-256 и скачивает только отсутствующие или изменившиеся данные. Папки 1.12.2 и 1.20.1 полностью разделены; нужные Java 8 и Java 17 устанавливаются автоматически.

## Структура

```text
client/                       файлы, которые попадут в папку игры
profiles/forge-1.20.1/        отдельные клиент и манифест Port Lab
launcher/                     bootstrap, обновляемое ядро и его канал
tools/                        генератор и проверка манифеста
manifest.json                 список файлов, размеров и SHA-256
deleted-paths.txt             старые файлы, которые надо удалить у игроков
1 - ОБНОВИТЬ МАНИФЕСТ.cmd     обновляет манифесты обоих профилей
2 - ПРОВЕРИТЬ ПАПКУ.cmd       двойной клик перед Push origin
ИНСТРУКЦИЯ_С_НУЛЯ_RU.md       инструкция для владельца
```

Не добавляйте сюда `saves`, Microsoft-токены, пароли, серверный мир, оригинальные JAR Minecraft, папки `assets`, `libraries` и `versions`.

Этот репозиторий предназначен для небольшой частной сборки. Права на сторонние моды, ресурсы и библиотеки принадлежат их авторам. Перед публичным распространением сборки за пределами своей компании друзей проверьте лицензии и правила распространения каждого проекта.
